# Rendering Patterns Demo (Modular CSR, SSR, SSG)

A minimal, lightweight Express application demonstrating **Client-Side Rendering (CSR)**, **Server-Side Rendering (SSR)**, and **Static Site Generation (SSG)** kept in separate, dedicated files with minimal code and simple comments.

---

## 📂 File Breakdown

```
rendering-pattern/
├── data.js          # Shared mock data source (products list)
├── csr.js           # Client-Side Rendering module (empty HTML shell + browser fetch JS)
├── ssr.js           # Server-Side Rendering module (renders full HTML per request)
├── ssg.js           # Static Site Generation script (build-time pre-rendering)
├── server.js        # Main Express server mounting all pattern routes
├── dist/            # Output folder for SSG static build assets
│   └── ssg.html     # Pre-rendered static HTML file generated by ssg.js
└── package.json     # Project configuration and scripts
```

---

## 📌 Pattern Comparison

| Pattern | Source File | Render Location | Render Time |
| :--- | :--- | :--- | :--- |
| **CSR** | [`csr.js`](file:///home/inxee-frontend/nikhil/frontend-system-design/performance/rendering-pattern/csr.js) | Browser (Client) | On client page load (via client JS `fetch`) |
| **SSR** | [`ssr.js`](file:///home/inxee-frontend/nikhil/frontend-system-design/performance/rendering-pattern/ssr.js) | Server | Dynamically on every incoming HTTP request |
| **SSG** | [`ssg.js`](file:///home/inxee-frontend/nikhil/frontend-system-design/performance/rendering-pattern/ssg.js) | Build Server | Once during build time (`npm run build`) |

## 🚀 How to Run

### 1. Build the SSG page
Executes `ssg.js` to pre-render `dist/ssg.html`:
```bash
npm run build
```

### 2. Start the Server
```bash
npm start
```

Or run both in one command:
```bash
npm run dev
```

### 3. Test Routes
- Dashboard: [http://localhost:3000/](http://localhost:3000/)
- CSR Demo: [http://localhost:3000/csr](http://localhost:3000/csr)
- SSR Demo: [http://localhost:3000/ssr](http://localhost:3000/ssr)
- SSG Demo: [http://localhost:3000/ssg](http://localhost:3000/ssg)
